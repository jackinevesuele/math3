# math3

Все пять задач листка 3 «Прикладные дифференциальные уравнения» П. Е. Рябова.

Основной файл: [Листок_3.ipynb](Листок_3.ipynb). Вариантов в листке нет.

| Задание | Что выполнено |
|---|---|
| 3.1 | Равномерный вертикальный спуск, полукубическая парабола |
| 3.2 | Бильярд, развёртка, периодичность, поток на торе |
| 3.3 | Цепная линия, равновесие сил, семейство форм |
| 3.4 | Уравнение Абеля, циклоида, одинаковое время спуска |
| 3.5 | Маятник, эллиптические функции, фазовый портрет |

В ноутбуке сохранены результаты, PNG и пять анимаций с управлением.
Статические рисунки — в [figures](figures), анимации — в [animations](animations).
GitHub может не показывать интерактивный HTML: скачайте HTML и откройте его в браузере
либо откройте доверенный ноутбук в Jupyter и выполните ячейки.

Краткое объяснение задач и формул: [Теория_и_защита.md](Теория_и_защита.md).

Для повторного запуска: `python -m pip install -r requirements.txt`, затем `jupyter lab`.
В Jupyter выберите Restart Kernel and Run All Cells. Интернет при выполнении не требуется.
Рисунки и анимации пересоздаются в каталогах рядом с ноутбуком.
